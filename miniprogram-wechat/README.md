# 合拍微信小程序演示

原生微信小程序演示，仅保留匹配、消息/双人故事卡和我的三个页面。没有 AI 功能。

## 导入预览

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选本 `miniprogram-wechat` 文件夹。
3. `project.config.json` 已填入你提供的 AppID。
4. 页面中的匹配人物均为虚构样例；登录、真人匹配、私聊、举报审核、支付和定位都没有接入。不要把演示当成已上线服务。

每日十次计数只存在本机，不能作为正式账号额度。正式运行需要账号和服务端。

## 上架前先确认

在微信公众平台后台核对个人主体能否申请“社交/陌生人交友”实际对应的服务类目，以及类目资质清单。当前演示不收款。微信支付小程序支付有主体准入限制；不要以个人二维码或私下转账替代平台支付。
