# 合拍微信小程序原生演示工程

这是微信小程序原生 WXML/WXSS/JavaScript 页面工程，含匹配、聊聊、记忆和我的四个页面。当前全部处于演示模式：候选人是虚构资料；聊天不发送到 AI；登录、真人匹配、举报审核、支付、定位和在线人数都未接入。

## 导入开发者工具

1. 安装微信开发者工具并使用你自己的微信管理员账号登录。
2. 选择“导入项目”，项目目录选择本 `miniprogram-wechat` 文件夹。
3. 当前 `project.config.json` 用的是体验用 `touristappid`。要上传审核，需先在微信公众平台注册/认证小程序，取得 AppID，再替换 `project.config.json` 中的 `appid`。
4. 开发工具可以本地预览原型。真实登录/支付/API 仍未实现，不能提交为正式运营版本。

## 正式服务所需接入

- 将 `app.js` 的 `demoMode` 改为 `false`，并配置已备案的 HTTPS API 域名。
- 使用服务端完成微信登录凭证校验；密钥只保存在服务端。
- 接入正式成年用户核验、内容安全审核、举报与申诉、真人匹配、记忆授权/撤回和数据删除。
- 在实现并审核通过支付渠道、服务端余额账本、扣费、防重放和退款前，保持充值和 AI 调用关闭。
- 依微信公众平台当期服务类目要求提交真实主体与资质；不要通过改名或隐藏功能来规避审核。

平台规则、资质和可用类目以提交时公众平台后台显示为准。此工程不会自动获得上线资格。
