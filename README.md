# 合拍 · AI 交友匹配原型

这是为中国大陆使用场景准备的手机网页原型与 Python API 起步工程。当前版本支持交互演示、年龄确认、一次性记忆授权、模型 API 服务端接入、加密保存聊天记录、查看/导出和删除记忆、删除全部访客数据，以及可直接进入的年龄/城市匹配筛选和举报表单预览。AI 聊天为自愿功能，不是匹配前提；本机演示在开启记忆后会按明确保存的偏好对样例候选作简单重排，不代表真实 AI 推荐或真人匹配。举报目前不上传、不调用 AI 审核，也不真实处罚。另有 AI 充值、匹配加次、VIP、同城定位和在线人数的价格/功能入口预览。

**它还不是可以公开营业的交友服务。** 当前没有真实支付、充值账本、AI 用量扣费、匹配次数/VIP 权益、定位城市解析、在线人数、微信登录、服务端年龄核验、完善内容安全、真人资料与匹配、举报运营、生产级授权与数据保留机制、合规评估和备案。联网原型前后端都会阻止真实模型调用，避免服务使用者消耗运营者的模型账户；不会假装收款或展示真实人数。不要把含个人数据的原型服务器暴露到公网。

## 打开交互原型

直接用浏览器打开 `合拍-交互原型.html`，体验不联网的交互演示。演示 AI 回复和推荐人选均为本地模拟，不调用真实模型，不收钱，也没有真实用户。充值页能预览价格，但点击金额不会创建订单或扣款。

## 本机启动联网后端

请使用 Python 3.11+，按 `server/README.md` 配置 `.env` 和 PostgreSQL，再进入 `server` 目录安装依赖并运行 FastAPI。通过 `http://127.0.0.1:8000` 打开原型，模型 API Key 只放在服务端环境变量。

模型服务未配置时，后端不会伪装成 AI 或回落到模拟回复；即使模型配置成功，前后端也会在计费未上线时阻止调用。请勿为了试运行而取消这个保护，直到服务端完成支付通知验签、充值账本、用量结算、退款和防重复扣款。具体价格、实现要求、数据边界和上线缺项见 `产品实现蓝图.md` 和 `AI行为与长期记忆设计.md`。

## 中国大陆发布方向

采用中国大陆云服务商的计算、数据库、域名和备案路线；当前代码按阿里云百炼北京地域模型接口预留适配器。发布小程序或网页前，先落实服务主体、隐私政策、数据处理和安全措施，完成适用的备案/登记/平台审核。不要把数据库口令、模型密钥或用户数据提交到公开仓库。
