# 合拍｜同城交友演示

本项目已按当前方向移除 AI 聊天、AI 画像、长期记忆、AI 充值和相关后端代码。当前提供年龄/城市筛选、每日 10 次本机演示匹配、消息页概念和一段预写双人故事卡。

## 重要边界

- 网页和小程序里的人物都是虚构样例；打招呼、举报、消息和匹配都没有连接真实用户。
- 每日 10 次仅保存在当前浏览器/设备，不是跨设备账号权益；清除本机数据会重置。
- 当前没有登录、真人资料、匹配服务端、实时消息、支付、充值或打赏入口。
- 你的 AppID 已写在 `miniprogram-wechat/project.config.json`。AppID 不是密钥；不要提交 AppSecret。
- 交友服务类目未获微信后台确认前，不能把它当成可发布的正式小程序。个人主体的陌生人交友类目需要先在你的后台核实。

## 预览

直接在浏览器打开 `合拍-交互原型.html`；微信开发者工具导入 `miniprogram-wechat/`。两者目前都只演示界面，不提供真人社交服务。

## 下一步发布门槛

先在微信公众平台查看该账号能否选择与陌生人匹配对应的“社交/陌生人交友”服务类目，以及所需资质。若类目不开放或资质达不到，删除 AI 并不能解决交友类目问题。正式产品还需大陆服务端、实名认证/年龄保护、内容审核、举报申诉和隐私治理。

微信支付小程序支付支持个体工商户、企业、事业单位、政府机关和社会组织等主体，个人小程序主体不在准入类型内。[微信支付：小程序支付准入条件](https://pay.wechatpay.cn/doc/v3/merchant/4012791894) 公众号“赞赏”主要用于符合条件的原创文章，不等于任何小程序都能放通用打赏按钮。
